# Isaac

普通《The Binding of Isaac: Wrath of the Lamb》网页版本，供 iPhone Safari 横屏运行。入口是仓库根目录的 index.html。

仓库包含完整 game.swf、本地 Ruffle JavaScript/WebAssembly、PWA 离线缓存与图标，以及完整网页源码。触控包含移动和射击双摇杆、炸弹、卡牌/药丸、主动道具快捷区；设置可调控件大小、透明度和位置。

页面不引用外站脚本或媒体资源；SWF 网络访问由运行器配置限制。通过 GitHub Pages/HTTPS 首次打开后缓存本站资源，之后可离线启动。iOS 可能在存储压力下清理站点缓存。

详见 README-APP.md。
